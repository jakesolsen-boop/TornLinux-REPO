`TornLinux-1.5.2-TEST-BuILD` project tree.

copies meant for experimentation and later selective integration.

Current baseline:

- seeded from the current `TornLinux-1.5.2-TEST-BuILD` files
- ready for reapplying richer TornStats/header work

Primary targets:
- richer in-app TornStats overlay

- compact combat badge
- colored resource cards for energy, happiness, nerve, and life
